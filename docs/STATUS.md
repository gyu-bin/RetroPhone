## 4. 기술적 제한 (iOS 정책상 불가능하여 구현하지 않음)
- 실제 시스템 홈 화면 변경, 설치 앱 목록 조회, 타 앱 배지·UI 변경, 타 앱 실행 상태 제어.
- 기존 문자/통화 기록, Apple 메모 데이터, 통신사명·신호 세기, Apple Watch·AirPods 배터리 조회.
- 다른 앱이 iOS 홈으로 강제 이동시키는 기능 → 사용자가 홈 제스처로 이동 (시스템 제스처를 막지 않음).
- 알람은 iOS 로컬 알림으로 울리며 시스템 시계 앱을 제어하지 않음.
- WeatherKit은 유료 개발자 계정 Capability가 필요해 기본값은 Open-Meteo(비상업적 무료).
- 카메라 촬영 시 시스템 셔터음은 iOS가 재생하며 일부 지역(한국 포함)에서 끌 수 없음 → 별도 합성 셔터음은 재생하지 않음.

## 5. 미해결 문제 / 다음 작업
1. **실기기 기능 검증 미완료** — iPhone 14 Pro에 설치·실행만 확인. 카메라·통화·문자·햅틱·배터리·외부 앱 실행·성능/배터리 소모와 iPhone 17 확인이 남음.
2. 홈 화면: 길게 눌러 편집 모드에 들어간 직후에는 손을 떼었다가 다시 끌어야 이동이 시작됨(iOS 4는 그대로 이어서 끌 수 있었음).
   - 참고: 이번 환경의 시뮬레이터 자동 탭 도구는 SwiftUI 아이콘 탭을 간헐적으로 놓쳤으나, XCUITest의 실제 터치에서는 정상 동작함을 확인. 실기기 손가락 입력으로 재확인 필요.
3. 애니메이션 곡선은 추정치이며 iOS 4 영상과의 프레임 단위 비교는 하지 않음.
4. 첨부 디자인 시안이 전달되지 않아 iOS 4 원래 디자인 기준으로 제작 (앱 아이콘만 사용자 시안 반영).
5. 메모 앱 긴 글에서 커서가 키보드에 가려질 수 있음 / 브라우저 탭은 재실행 시 복원되지 않음 / 지도 경로는 자동차만.
6. 음성 메모 라벨 "메모"가 영어에서 "Notes"로 표시됨(문자열 테이블 충돌).
7. `CLGeocoder`(deprecated) → MapKit 지오코딩으로 교체 필요.
8. 메모리 누수(Instruments), 장시간 실행 안정성, 라이트/다크 환경 확인 미실행. (앱은 항상 라이트 외관으로 고정)
9. App Store 배포 가능성(심사 지침 2.5.8, 4.1 등)은 별도 검토 필요. 앱 아이콘에 iPhone 형태가 들어가 있어 Apple 하드웨어 이미지 사용 제한에도 걸릴 수 있음(개인 설치에는 무관).
